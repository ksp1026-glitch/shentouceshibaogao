## 写题解的原则

1. **写思路，不只写答案。** 「我怎么想到这一步的」比最终 flag 更有价值
2. **卡住的地方要记录。** 踩过的坑才是真正学到的东西
3. **注明考点。** 每道题解开头写清楚考什么（如：SQL 盲注、PHP 弱类型、文件包含）
4. **比赛题目注意规则。** 部分比赛禁止赛后公开题解，写之前确认一下
