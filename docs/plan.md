# 学习计划

本学期（大三上）的目标：**建立渗透测试基础 + 产出第一批 writeup**。

时间安排：工作日不碰渗透测试，全部集中在**周末 6 小时**。

---

## 总体节奏

| 阶段 | 时间 | 目标 |
|---|---|---|
| 阶段 0 | 第 1-2 周 | 环境搭建、Linux 基础、Burp Suite 上手 |
| 阶段 1 | 第 3-8 周 | Web 漏洞逐个击破，产出 18 份 writeup |
| 阶段 2 | 第 9-11 周 | 实战记录、CTF 入门、漏洞平台提交 |
| 阶段 3 | 第 12-16 周 | **全线暂停**，专注期末考试 |

!!! warning "期末优先"

    第 12 周起停止一切渗透测试练习。GPA 是这个学期唯一不可逆的指标，其他都可以等。

---

## 逐周清单

### 阶段 0：环境搭建

- [ ] **第 1 周** — 装 VMware + Kali，Docker 起 DVWA 和 Pikachu，建好本仓库

**验收**：能独立完成「打开 DVWA → Burp 抓到登录请求 → 改包重放」。

### 阶段 1：Web 漏洞

每周一个主题，打两个靶场，写 2 份 writeup。

- [ ] **第 3 周** — SQL 注入（上）：数字型、字符型、联合查询
- [ ] **第 4 周** — SQL 注入（下）：盲注、报错注入、宽字节
- [ ] **第 5 周** — XSS：反射型、存储型、DOM 型
- [ ] **第 6 周** — 文件上传 + 文件包含
- [ ] **第 7 周** — 命令注入 + 目录遍历 + CSRF
- [ ] **第 8 周** — SSRF + XXE + 逻辑漏洞

### 阶段 2：实战

- [ ] **第 9 周** — VulnHub 入门机器，走完整渗透流程，产出 1 份完整报告
- [ ] **第 10 周** — CTF 入门（Bugku / CTFHub / 攻防世界），10-15 道题
- [ ] **第 11 周** — 注册补天 / 漏洞盒子，尝试首次提交

### 阶段 3：期末

- [ ] **第 12-16 周** — 渗透测试暂停，只整理归档已有 writeup

## 每周时间分配（6 小时）

```
周六 4h
├─ 0.5h  看当天主题的原理资料
├─ 2.5h  打靶场（手工优先）
└─ 1.0h  写 writeup

周日 2h
├─ 1.0h  补上周没打完的靶场
└─ 1.0h  完善 writeup + 更新索引
```

!!! tip "关键比例"

    **打靶场 3.5h，写 writeup 2h，看资料 0.5h。**

    很多人把 5 小时全花在打靶场上，结果零产出。**writeup 才是资产，靶场只是手段。**

---

## 三条纪律

1. **只打授权靶场。** 不碰任何真实网站，一次都不行。
2. **每打完一个必须写 writeup。** 没写的等于没打。
3. **期末前 4 周全线停。** GPA 优先。
